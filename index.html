At RAKBANK, I built the bank's Design Language System, an atomic-design React component library now used across 4 to 5 applications, and an internal CLI that sets up new projects with the org's structure, testing and tooling already in place. New project setup is about 40% faster with it. I've also delivered the KYC and customer lifecycle platforms used by the personal banking teams, and right now I'm working on a config-driven platform where screens are rendered from JSON configuration instead of written by hand. On the testing side, we maintain 80% unit test coverage.

I've been doing this since 2019. Before RAKBANK, I led the rebuild of a lead management CRM in Next.js 14 at LastingSales and introduced TypeScript to the codebase. Before that, I worked full-stack at Brisk Solutions on an ERP platform that consolidated several .NET systems into one React, Node.js and MySQL platform.
